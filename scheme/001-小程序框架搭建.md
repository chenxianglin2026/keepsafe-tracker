# KeepSafe 小程序开发方案 #1 — 框架搭建

> 版本：v1.0
> 开发者：OpenClaw + Hermes
> 前置条件：微信小程序 AppID（等待中）

---

## 1. 需求

搭建微信小程序的基础框架，包括：
- 项目结构
- 页面路由
- UI组件库选择
- 后端API对接封装
- 地图组件集成

## 2. 技术方案

| 项 | 选择 | 原因 |
|----|------|------|
| 框架 | 微信原生小程序 | 最简单、体积最小、微信支持最好 |
| 地图 | 微信原生 map 组件 | 免费、不需要额外接入高德/百度 |
| UI库 | 不引入第三方库 | 页面简单，自己写更可控且体积更小 |
| 状态管理 | 无（小程序够用） | 项目小，不需要Vuex/Redux |
| 请求封装 | wx.request 封装 | 统一处理Token/错误 |

## 3. 页面结构

```
pages/
├── index/             首页（实时地图）
├── device/            设备详情
├── fence/             围栏设置
├── sos/               SOS告警页
├── login/             微信登录
└── bind/              扫码绑卡

components/
├── map-view/          地图组件
├── device-card/       设备状态卡片
├── fence-picker/      围栏选择器
└── sos-alert/         SOS告警弹窗

utils/
├── api.js             后端API封装
├── mqtt.js            MQTT连接
├── location.js        定位工具
└── notify.js          通知工具
```

## 4. 后端API（我先搭好）

```
POST /api/login          — 微信登录
POST /api/device/bind    — 扫码绑卡
GET  /api/device/list    — 设备列表
GET  /api/device/:id     — 设备详情
GET  /api/location/:id   — 实时位置
POST /api/fence          — 创建围栏
GET  /api/fence/list     — 围栏列表
POST /api/sos            — SOS告警
```
