## 四、结构要求

### 4.1 外壳设计

| 项目 | 要求 |
|------|------|
| 外形 | 扁长方体，四角大圆角（R3-5mm） |
| 外部尺寸 | 38mm × 28mm × 10mm |
| 材质 | PC+ABS（外壳）+ 医用硅胶（外套） |
| 防水 | IP65（硅胶密封圈） |
| 表面 | 磨砂质感（老人）/ 肤感（儿童） |

## 五、SOS求救操作流程

```
短按 < 1秒  → 振动马达响应200ms（按键确认）
长按 3 秒  → 长振动500ms（确认触发）
           → 蜂鸣器 ≥85dB 尖叫30秒
           → LED高频闪烁30秒
           → 家人微信收通知+实时位置
按任意键    → 停止蜂鸣和闪光
```
