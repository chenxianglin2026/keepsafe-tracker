## 四、SOS求救硬件规格

| 组件 | 规格 | 说明 |
|------|------|------|
| 🔊 蜂鸣器 | ≥85dB @ 10cm，8×8×3mm | SOS触发时持续尖叫30秒 |
| 💡 LED指示灯 | 高亮白光/红光，Φ2mm | SOS时高频闪烁，夜间可见 |
| 📳 振动马达 | 4×8×2mm，扁平 | 按键确认反馈、SOS反馈 |
| 🔘 SOS按键 | Φ12mm，凹面，行程1.5mm | 长按3秒触发，凹面防误触 |

### SOS触发流程（结构相关）

```
短按 < 1秒  →  振动马达响应 200ms（确认按键）
长按 3 秒  →  振动马达持续振动 500ms
            →  蜂鸣器开始鸣叫 30秒
            →  LED 高频闪烁 30秒
按任意键    →  停止蜂鸣和闪光
```

## 五、装配与工艺要求

| 项目 | 要求 |
|------|------|
| 外壳合模 | 上下壳卡扣固定，无需螺丝 |
| 防水密封 | 壳间嵌入硅胶密封圈（IP65） |
| USB-C防水 | 充电口带防水塞或IP65级母座 |
| SOS按键防水 | 硅胶按键一体成型，防水透声 |
| 蜂鸣器防水 | 出声孔内侧覆防水透声膜 |
| 天线区域 | 外壳对应区域不得使用金属材质 |
| 表面处理 | 磨砂质感（老人款）/ 肤感（儿童款） |

## 七、交付给结构工程师的清单

```

□ 1. 外壳3D模型（.stp/.step格式）

结构工程师确认后给我审核：

□ SOS按键手感是否合格

```
