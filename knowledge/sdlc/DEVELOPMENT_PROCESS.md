# 开发管理流程

## 7 步工作流

1. **你提需求** → 一句话描述
2. **我写开发方案** → 产出 `designs/KF-xxx-名称.md`
3. **你审批方案** → 你点头
4. **我派 Agent 开发** → `delegate_task` 按角色分配
5. **QA 测试** → 独立测试 Agent
6. **Reviewer 验证** → 独立审查（不同人）
7. **归档 + 汇报** → 知识库更新 + 结果给你

## 核心规则

- 📋 **方案先行**：没方案不开发
- 👥 **代码不自审**：开发 Review 不同人
- ⚡ **P0 清零**：发布前必须
- 🚨 **异常上报**：Agent 连续失败 2 次找我
- 🔑 **密钥不碰**：所有密钥必须你亲手填
- 🎯 **结果导向**：你只看结果
