## 术语表

| 术语 | 解释 |
|------|------|
| PSM | Power Saving Mode，省电模式，设备深度睡眠 |
| Cat.1 | 4G通信标准，适合物联网，速率够用功耗低 |
| BLE | 蓝牙低功耗，短距离通信 |
| LBS | 基站定位，通过手机塔估算位置 |
| OTA | 远程固件升级 |
| SOS | 紧急求救 |
| 电子围栏 | 虚拟地理边界，进出触发告警 |
| BIM | Boss Is Moderate — 陈总说了算 |
