## 一、最终芯片选型：EC618

### 1.1 决策

| 项目 | 内容 |
|------|------|
| 最终方案 | **EC618 (移芯 Cat.1 通信芯片)** |
| 决策日期 | 2026-06-05 |
| 替换方案 | 展锐 8910 (原选型，已放弃) |
| 决策人 | 陈总 + Hermes |

### 1.2 选型对比

| 维度 | EC618 (移芯) | 展锐 8910 (原方案) | 结论 |
|------|-------------|-------------------|------|
| 通信制式 | Cat.1 bis (3GPP Rel.13) | Cat.1 | EC618 更省成本 |
| 集成度 | 内置 PMU + Flash + PSRAM | 需外挂 Flash | EC618 外围更简 |
| BLE | 需外挂 BLE SoC | 内置 BLE 5.0 | 8910 集成的更优，但 EC618 + 外挂 BLE 芯片灵活 |
| 成本 | ~¥12/片 | ~¥18/片 | EC618 省 ¥6/片 |
| 供货 | 移芯直销 + 淘宝/1688 | 展锐渠道较窄 | EC618 渠道更多 |
| 开发生态 | 标准 AT 指令 + LuatOS 可选 | 展锐 SDK 封闭 | EC618 门槛更低 |
| 功耗 | 1.5μA PSM 深度睡眠 | ~2μA PSM | EC618 略优 |

### 1.3 最终硬件架构

```
EC618 (Cat.1 通信) — 负责 4G + MQTT 上报
    │
    ├── UART ── BLE SoC (如 CH582M) — 负责蓝牙扫描 + 断连告警
    │
    ├── I2C ── LIS3DH 加速度计 — 运动检测
    │
    ├── GPIO ── LED + 蜂鸣器 + 振动马达 — SOS 模块
    │
    └── UART ── GNSS 模块 (合宙 Air530) — GPS+北斗定位
```
