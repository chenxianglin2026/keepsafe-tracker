## 整体设计风格

```
色彩方案：
  🟢 主色：#4CD964  — 绿色（安全、放心）
  🔴 警告色：#FF3B30 — 红色（SOS、紧急）
  🔵 功能色：#007AFF — 蓝色（可点击）

字体：
  • 正文 ≥ 16px（适老化）
  • 标题 ≥ 20px
  • SOS页 ≥ 32px（超大）

按钮：
  • 高度 ≥ 48px（手指友好）
  • 圆角 12px
  • 有大面积触控区域

布局：
  • 卡片式设计（白底圆角）
  • 信息层级分明
  • 三步内完成核心操作
```

## 小程序页面结构

```
┌─ 启动页 ──────────────────────────┐
│   微信授权登录 → 绑定手机号         │
└────────────────────────────────────┘
                    ↓
┌─ 首页（默认） ─────────────────────┐
│   实时地图 · 当前位置 · 设备卡片    │
└────────────────────────────────────┘
         ↙           ↘            ↘
┌─ SOS告警 ─┐ ┌─ 围栏设置 ─┐ ┌─ 设备 ──┐
│ 大红色     │ │ 列表+添加  │ │ 详情    │
│ 导航+电话  │ │ 开关管理   │ │ 设置    │
└───────────┘ └───────────┘ └─────────┘
```
