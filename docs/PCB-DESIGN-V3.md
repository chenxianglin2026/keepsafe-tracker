```
Air780EG                         外设
─────────────────────────────────────

GPIO3    (10)       → 按键 (上拉10KΩ→3.3V, 按下→GND)
GPIO4    (11)       → 蜂鸣器 (经NPN三极管驱动)
UART1_TX (55)       → 测试点 TP1 (调试用)
UART1_RX (56)       → 测试点 TP2 (调试用)
USB_DP   (49)       → 测试点 TP3
USB_DM   (50)       → 测试点 TP4

PWRKEY   (20)       → 开机键 (已集成在模组)
```

## 四、PCB Layout 要求

### 叠层结构
```
┌──────────────────────────┐
│  顶层 (Top Layer)         │  ← 模组 + 天线 + LED + 按键 + 阻容
│  信号走线                 │
├──────────────────────────┤
│  FR-4 基板 1.0mm          │
├──────────────────────────┤
│  底层 (Bottom Layer)      │  ← SIM卡座 + 蜂鸣器 + 电池座
│  完整地平面               │
└──────────────────────────┘
```

### 布局要求
1. Air780EG 模组居中放置
2. GPS 天线放在板边角落，地平面下方净空
3. 4G IPEX 座放在板边，便于天线引出
4. SIM卡座放在底层(底面)
5. LED + 按键放在顶层便于交互
6. 电池座放在底层板边
7. 天线区域 10mm 内无铜皮

### 走线要求
1. 天线射频走线用 50Ω 阻抗控制，线宽约 0.45mm
2. SIM卡信号走线长度 < 50mm，包地处理
3. 电源走线加粗 > 0.5mm
4. 所有GPIO走线 0.2mm
