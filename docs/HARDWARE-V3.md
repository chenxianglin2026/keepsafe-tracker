### 2.2 重点分析：为什么A780E/Air780EG是首选

**合宙Air780E (推荐用于 无GNSS需求 场景):**
- 芯片EC618 22nm制程，功耗最低(PSM 1.5μA)
- 内置Flash+PSRAM，外围极简，BOM最省
- 合宙直销¥14-25，渠道透明
- LuatOS-SoC固件：Lua脚本开发，极低门槛
- AT固件：标准MQTT AT指令集，30分钟上手
- 完全开源，MQTT Broker地址可自由配置
- 社区最活跃，文档最全

**合宙Air780EG (推荐用于本项，已内置GNSS):**
- 与Air780E同一平台，额外内置GNSS引擎
- 内置GPS+北斗双模定位
- 支持 AGNSS (星历预下载) 加速冷启动
- 省去外挂GNSS模组的成本(¥8-15)和PCB面积
- 单芯片搞定 4G Cat.1 + GNSS定位
- 淘宝¥28-35，批量¥20-22

### 2.3 为什么不选其他

## 三、MCU选型：要不要外挂MCU？

### 3.1 关键决策：单芯片 vs 双芯片

| 架构 | 方案 | 优点 | 缺点 |
|------|------|------|------|
| **单芯片** | Air780EG SoC直接开发 | BOM最低(¥22)；PCB面积最小；功耗最低 | 开发语言Lua/AT，不如C灵活 |
| **双芯片A** | MCU + Air780E (AT) | ESP32-S3生态成熟；C语言开发 | BOM增加¥15-25；PCB面积增加；功耗增加 |
| **双芯片B** | MCU + Air780EG (AT) | 同上+利用Air780EG内置GNSS | BOM增加¥15-25；GNSS通过AT获取 |

## 四、GNSS方案分析

### 4.1 核心决策：Air780EG已内置GNSS

Air780EG的EC618芯片内置了GNSS基带引擎，支持:
- GPS L1 C/A
- 北斗 B1I/B1C  
- GLONASS L1 (部分固件)
- 冷启动: 约35秒(空旷室外)
- 热启动: 约3秒
- 灵敏度: -148dBm (追踪), -144dBm (冷启动)
- AGNSS星历预下载加速


### 7.2 关键设计注意

1. **GNSS天线与4G天线间距** ≥ 10mm，避免互调干扰
2. **GNSS天线到Air780EG的RF走线** 用50Ω微带线，尽量短(<5mm)
3. **4G天线** 通过IPEX连接器引出FPC天线，贴于外壳内壁
4. **电池连接器** 靠近PMIC，电源走线加粗(≥1mm)
5. **SIM卡座** 靠近Air780EG的SIM接口引脚
6. **GND完整性** Bottom层尽量完整覆铜做地平面
7. **板厚1.0mm** 比1.6mm省0.6mm厚度，对10mm外壳极其关键

### 8.2 续航估算 (200mAh电池)

**场景A：正常待机模式 (每30分钟上报一次位置)**

```
每天24小时:
  - PSM睡眠: 23.9h × 0.004mA = 0.096mAh
  - eDRX寻呼窗: 0.08h × 0.2mA = 0.016mAh
  - 定位上报(48次×13s): 0.17h × 126mA = 21.4mAh
  ─────────────────────────────────────
  日耗电: ~21.5mAh
  续航: 200mAh / 21.5mAh = 约 9.3 天 ✅
```

**场景B：省电模式 (每2小时上报一次)**

```
  - 日耗电: ~5.5mAh
  续航: 200mAh / 5.5mAh = 约 36 天 ✅✅
```

**场景C：持续追踪 (每30秒上报)**

```
  - 平均电流约 40mA
  续航: 200mAh / 40mA = 约 5 小时
```

## 十三、关键警告 ⚠️
