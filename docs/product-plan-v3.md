## 二、芯片方案重新选型

### 方案对比

| 芯片 | 制程 | 集成度 | 功耗 | BOM成本 | 成熟度 |
|------|------|--------|------|---------|--------|
| **ASR1606** (旧选) | 28nm | 中 | 中等 | ¥22 | ✅ 成熟 |
| **展锐8910** ⭐ | 28nm | 高 | 更低 | **¥18** | ✅ 成熟 |
| **ASR1603** | 28nm | 低 | 更低 | ¥15 | ⚠️ 需要外挂GPS |
| **移芯EC618** | 22nm | 高 | 最低 | **¥16** | ✅ 新但稳 |

**推荐：展锐8910 或 移芯EC618**

理由：
- 展锐8910：集成度最高（GPS+BLE+4G一体），不需要外挂GPS模块，省¥10
- 移芯EC618：22nm更省电，续航还能多5-7天
- 两个都能做到 `BOM成本 ¥49.5`（比之前的¥59.5省¥10）

```

──────────────────────────    ──────────────────────────

GPS模块             ¥10       (集成在芯片内)    ¥0

```

**BOM从¥59.5降到¥43，省了¥16.5！**

## 三、续航再优化

### 优化策略（纯软件，零成本）

| 策略 | 说明 | 省电效果 |
|------|------|---------|
| 🔋 **动态上报频率** | 静止时不定位，走动5分钟/次，跑动1分钟/次 | +5天 |
| 🌙 **夜间免打扰** | 22点-6点不上报GPS，基站定位1次/小时 | +3天 |
| 🧠 **学习轨迹预判** | 知道"家"和"常去地点"后，在已知区域减少上报 | +3天 |
| 📉 **低电量模式** | 低于20%时降低所有频率 | +5天(最后20%) |
| 📶 **批量上报** | 攒5个位置一次发，减少4G唤醒次数 | +2天 |

### 优化后续航

| 模式 | V2方案 | V3优化后 | 
|------|--------|---------|
| 日常使用 | 36天 | **45-50天** ✅✅ |
| 最低保障 | 30天 | **35天** ✅ |
| 追踪模式(应急) | 10天 | 10天（不变） |

**对外宣称"超长续航30天"，实际多数用户能到45天以上。**

## 四、结构尺寸重新设计

### 方案A：40×30×10mm（推荐 ✅）

```
原9mm → 10mm 只厚1mm，但：
- 内部高度 7→8mm，空间从容
- 可以采用标准电池装配
- 生产良率更高
- 几乎没有外观差异
```

### 方案B：如果能用展锐8910（集成芯片）

```
芯片高度从 3mm(GPS模块) → 1mm(集成)
省出2mm厚度空间

→ 可以做到 38×28×8mm！
  — 比40×30更小、更薄
  — 还没有天线干扰问题（集成芯片天线设计更简单）
```

**理想目标：38×28×8mm（比拇指指甲略大）**
