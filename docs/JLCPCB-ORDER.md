## 四、布局要求

### 顶层 (Top Layer)
```
┌──────────────────────────────┐
│  [ANT2] IPEX-1       [ANT1] │  ← 天线靠边
│          GPS陶瓷天线           │
│                               │
│     ┌─────────────────┐      │
│     │                 │      │
│     │  Air780EG 模组   │      │  ← 居中
│     │  17.7×15.8mm    │      │
│     │                 │      │
│     └─────────────────┘      │
│                               │
│  [D1]● [D2]●  [SW1]○ [BZ1]  │  ← LED+按键+蜂鸣器
│                               │
└──────────────────────────────┘
```

### 底层 (Bottom Layer)
```
┌──────────────────────────────┐
│                               │
│     ┌──────────────┐         │
│     │  SIM 卡座     │         │
│     │  15×14.7mm   │         │
│     └──────────────┘         │
│                               │
│                    [J3]电池座  │
└──────────────────────────────┘
```

### 天线要求
- GPS天线下方 10mm 范围内无铜皮（净空区）
- 4G天线射频走线阻抗 50Ω（线宽约0.45mm FR4 1.0mm）

## 五、引脚连接表

```
Air780EG 引脚 → 外设连接
─────────────────────────────
VBAT(1,2,3)  → 电池正极 (3.7V)
GND(4,5等)   → 地平面
ANT_MAIN(45) → IPEX-1(4G天线)
ANT_GNSS(67) → 陶瓷GPS天线(经匹配)
GPIO1(8)     → 绿LED→10KΩ→GND
GPIO2(9)     → 红LED→10KΩ→GND
GPIO3(10)    → 按键→10KΩ上拉→3.3V
GPIO4(11)    → 蜂鸣器(NPN驱动)
UART1_TX(55) → TP1测试点
UART1_RX(56) → TP2测试点
SIM_VDD(74)  → SIM卡座VDD
SIM_RST(75)  → SIM卡座RST
SIM_CLK(76)  → SIM卡座CLK
SIM_DATA(77) → SIM卡座IO
```
