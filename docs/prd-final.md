## 1. 产品概述

### 1.1 产品定位
一款面向老人和儿童的**迷你防走失定位系统**，比硬币略大、续航30天、售价¥199。通过定位器硬件 + 监护人手机 App + 微信小程序，实现实时定位、电子围栏告警、SOS 一键求救。

### 1.2 核心卖点
- **小** — 40×30×9mm，比一张名片小，重仅15g
- **久** — 30天超长续航，不用频繁充电
- **省** — 硬件¥199，月租¥5-8
- **全** — App + 微信小程序都能看

### 1.3 目标用户

| 用户角色 | 描述 | 核心需求 |
|---------|------|---------|
| **监护人**（子女/父母） | 30-50 岁 | 随时查看位置、接收告警、微信小程序快捷查看 |
| **老人**（60-85岁） | 记性不好、不擅用手机 | 挂绳佩戴、一键SOS、无需操作 |
| **儿童**（3-12岁） | 活泼好动 | 鞋带扣佩戴（摘不掉）、防走失 |

## 5. 用户场景

### 场景1：日常守护
```
早8:00 老人出门买菜
  → App看到老人位置
  → 正常活动，无告警
  → 随时看一眼确认平安
```

### 场景2：超出围栏告警
```
老人离开家周边500m
  → 定位器上报 + 后端计算超围栏
  → 监护人手机/微信收到推送
  → 打开App查看位置，打电话确认
```

### 场景3：SOS紧急求助
```
老人不适，长按SOS键3秒
  → 定位器震动反馈
  → 家人收到紧急推送 + 当前位置
  → 快速联系或前往
```

### 场景4：放学走失
```
孩子放学未按时到家
  → 家长打开App/小程序查看
  → 发现孩子偏离路线
  → 导航前往寻找
```

## 7. 开发计划

### Phase 1：MVP（3个月）
| 模块 | 内容 | 工时 |
|------|------|------|
| App | 注册绑卡、地图定位、围栏、SOS | 6周 |
| 微信小程序 | 实时定位、告警接收、设备管理 | 4周 |
| 固件 | 定位上报、SOS、低电量、省电 | 4周 |
| 后端 | 设备接入、位置存储、推送 | 4周 |
| 硬件 | 打板验证、天线调试 | 4周 |

### Phase 2：产品化（2个月）
- App完善：多设备、共享、轨迹
- 小程序完善：位置分享
- 固件优化：省电调优、OTA
- 外观：开模具、小批量试产
- 认证：入网许可、SRRC、CCC

### Phase 3：量产（2个月）
- 供应链确定、备料
- 可靠性、防水、续航测试
- 包装、说明书设计
- 电商上架

### 总周期：约7个月
