## 四、立体堆叠验证

```
顶壳内壁
  ↓ 0.5mm 间隙
  PCBA顶面 (元件最高USB-C=3mm)
  PCB板 1.6mm
  PCBA底面 (天线2mm)
  ↓ 0.5mm 间隙
  电池顶面
  电池 4.5mm
  ↓ 0.4mm 间隙
  底壳内壁
```

总堆叠: 0.5 + 3 + 1.6 + 2 + 0.5 + 4.5 + 0.4 = **12.5mm > 7.6mm** ❌

## 五、问题：堆叠超限！

当前堆叠 12.5mm 超过内腔 7.6mm。解决方案：

**方案A：双面布局（推荐）**
- PCBA 和电池不重叠，并排放置
- PCBA: 32×22mm，电池: 28×18mm
- 并排总宽: 22+18 = 40mm → 超出 25.6mm ❌

**方案B：电池减薄**
- 改用 200mAh: 25×16×3mm
- 堆叠: 0.5 + 3 + 1.6 + 2 + 0.5 + 3 + 0.4 = 11mm ❌ 仍超

**方案C：PCBA 嵌入电池凹陷区 ⭐**
- 电池做 L 型或 U 型，PCBA 嵌入电池缺口
- 或 PCB 采用软硬结合板，弯折包裹电池

**方案D：增加厚度到 12mm（推荐）⭐**
- 外壳从 10mm → 12mm
- 内腔: 35.6×25.6×9.6mm
- 堆叠: 12.5 → 需 12.5mm → 超 9.6mm。仍不行。

**方案E：分离式双板设计 ⭐⭐**
- 主板(展锐8910+GPS+SIM): 20×22×3.5mm
- 子板(电池保护+SOS+蜂鸣器): 12×22×2mm
- 电池: 28×18×4.5mm
- 并排: 主板20+子板12=32mm → 放 35.6mm ✅
- 垂直: max(3.5, 4.5) + 1 = 5.5mm → 放 7.6mm ✅

## 六、最终推荐方案

```
俯视图:              侧视图:
┌──────────────┐     ┌──────────┐
│ 天线区 10×8  │     │ 顶壳1.2  │
├──────┬───────┤     │ 主板3.5  │
│ 主板 │ 子板  │     │ 电池4.5  │
│20×22 │12×22  │     │ 底壳1.2  │
├──────┴───────┤     │   = 9.6  │
│ 电池 28×18   │     │  < 10mm ✅│
└──────────────┘     └──────────┘
```

PCBA: 35×22mm 双拼板 → 内腔 35.6×25.6 刚好 ✅
最高元件 4.5mm(电池) + 上下壁厚 2.4mm = 6.9mm → 外壳10mm ✅
