## 二、7个执行单元详解

### 核心层（3人）

| 单元 | 角色 | 位置 | 职责 | 汇报 |
|------|------|------|------|------|
| **陈总** | CEO/产品决策 | — | 定方向、审批、提供资源(AppID/Key/资金)、供应链、认证 | — |
| **OpenClaw** | CTO/技术总监 | VPS 43.163.5.90 | 技术架构、代码审查、固件编译、后端部署、工具安装 | → 陈总 |
| **Hermes** | PM/执行总监 | 本地 Mac | 日常管理、任务调度、开发执行、测试验证、文档归档、汇报 | → 陈总 |

### Hermes 直管 4 个执行单元

| 单元 | 覆盖的角色 | 工具集 | 何时激活 |
|------|-----------|--------|---------|
| **子代理-后端/App** | 后端工程师 + iOS工程师 + 小程序工程师 | terminal, file | API/App/小程序修改 |
| **子代理-硬件/嵌入式** | 嵌入式工程师 + 硬件工程师 + 结构工程师 | terminal, file | 固件/PCB/3D外壳 |
| **子代理-UI/前端** | UI/UX设计师 + 前端工程师 | terminal, file, vision | 界面设计/交互/适老化 |
| **子代理-QA** | 测试工程师 + 安全审查员 | terminal, file, search | 功能测试/安全审查 |

### OpenClaw 直管

| 职能 | 说明 |
|------|------|
| 固件编译 | ESP-IDF 编译环境 |
| 后端部署 | Docker + EMQX + PostgreSQL |
| 工具链安装 | KiCad, Blender, OpenSCAD 等 |
| 代码审查 | 所有代码最终把关 |
| CI/CD | 自动化构建 |

### 陈总直管

| 职能 | 说明 |
|------|------|
| 元器件采购 | BOM 采购，打样下单 |

## 六、不超负荷红线

- Hermes 同时管理 ≤ 4 个子代理
- 每个子代理单次 ≤ 5 个文件变更
- 复杂任务(5+文件)分多轮委派，每轮 ≤ 3个文件
- OpenClaw 不写业务代码，专注编译+部署+审查
- 子代理失败不阻塞全局 → Hermes 直接接手
