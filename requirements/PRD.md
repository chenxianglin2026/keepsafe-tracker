# 产品需求文档（PRD）

> 项目：KeepSafe — 老人小孩防丢器
> 版本：v1.0
> 状态：初稿

---

## 1. 产品概述

### 1.1 产品定位
一款面向老人和儿童的**防走失定位系统**，通过小型定位器硬件 + 监护人手机 App，实现实时位置查看、电子围栏告警、SOS 一键求救等功能。

### 1.2 目标用户

| 用户角色 | 描述 | 核心需求 |
|---------|------|---------|
| **监护人**（子女/父母） | 30-50 岁，智能手机重度用户 | 随时查看家人位置、接收告警、操作简单 |
| **被监护人——老人** | 60-85 岁，可能记性不好、不擅用手机 | 随身佩戴定位器，一键 SOS 求助 |
| **被监护人——儿童** | 3-12 岁，活泼好动 | 佩戴定位器，防走失、防意外 |

### 1.3 核心价值
- 让家人**随时知道老人/孩子在哪**
- 超出安全范围**自动告警**
- 紧急情况**一键求助**
- 所有操作**简单到不用教**

## 4. 用户场景

### 场景 1：日常守护
```
早 8:00  老人出门买菜
  → 监护人 App 看到老人位置在地图上
  → 正常活动，无告警
  → 可随时打开 App 看一眼确认平安
```

### 场景 2：超出电子围栏
```
老人离开家周边 500m 安全范围
  → 定位器上报位置 + 后端计算超出围栏
  → 监护人手机收到推送告警
  → 打开 App 查看位置，打电话确认
```

### 场景 3：SOS 紧急求助
```
老人感觉身体不适，长按定位器 SOS 键 3 秒
  → 定位器震动反馈确认
  → 监护人手机收到紧急推送 + 当前位置
  → 监护人可快速联系或前往
```

### 场景 4：儿童放学走失
```
孩子放学后未按时到家
  → 监护人打开 App 查看实时位置
  → 发现孩子在偏离路线的位置
  → 导航前往寻找
```

## 5. 非功能需求

| 类型 | 要求 |
|------|------|
| 定位精度 | 室外 ≤ 10m（空旷环境），室内 ≤ 30m |
| 告警延迟 | 从事件发生到推送 ≤ 5 秒 |
| 设备续航 | ≥ 7 天（1 次/分钟上报频率）|
| 设备防水 | IP65 以上 |
| App 崩溃率 | ≤ 0.5% |
| 后端可用性 | 99.9%（月宕机 ≤ 43 分钟）|
| 数据加密 | 传输 TLS 1.3，存储 AES-256 |
| 隐私合规 | 符合《个人信息保护法》|

## 6. 硬件规格（初定）

| 参数 | 规格 |
|------|------|
| 尺寸 | ≤ 50×35×15mm（略大于硬币盒）|
| 重量 | ≤ 40g |
| 电池 | 锂聚合物 800-1200mAh |
| 充电 | Micro USB / Type-C |
| 通信 | 4G Cat.1 / NB-IoT |
| 定位 | GPS + BDS + LBS |
| 传感器 | 加速度计（V1.0 预留，V2.0 跌倒检测用）|
| 按键 | SOS 键 × 1 |
| 指示灯 | 电量/联网状态 LED × 1-2 |
| 材质 | 医用级硅胶（儿童款）/ 亲肤塑料（老人款）|

---

## 7. 约束与限制

- 定位器需要 SIM 卡（4G 流量），有月费成本
- 室内定位精度依赖 WiFi/BLE 覆盖
- 部分功能（如跌倒检测）需要 V2.0 硬件支持
- 海外市场需额外认证（FCC/CE）
- 儿童使用需注意小零件吞咽风险
