# 外观结构设计规格书

> 版本：v1.0 | 提供者：老板

---

## 一、整机参数

| 参数 | 规格 |
|------|------|
| 外形 | 跑道圆角椭圆款 |
| 外尺寸 | 长 78mm × 宽 48mm × 厚 12mm |
| 风格 | 偏心挂耳、低专利侵权、适配老人握持、全鲁班尺吉位 |
| 内置 | MK 同款腔体喇叭、4G+北斗GPS、锂电池、SOS 键、指示灯、Type-C、振动马达 |

## 二、三视图与开孔尺寸

### 正面
| 特征 | 参数 |
|------|------|
| 四角圆角 | R8mm |
| 挂耳 | 顶部左侧偏心布局，总宽 10mm、总高 14mm、内孔直径 8mm |
| 喇叭区域 | 正面上半区居中，20×14mm 超薄腔体喇叭（MK 同款）|
| 出声孔 | 矩阵微孔阵列 |
| 指示灯 | 2 颗，分列喇叭下方左右，单孔 3mm，间距 6mm |
| SOS 键 | 正面下居中，直径 22mm，距底边 8mm |

### 侧面
| 特征 | 参数 |
|------|------|
| 厚度 | 12mm，侧边微圆弧度无棱角 |
| Type-C | 右侧居中开孔，预留防水胶槽 |

### 顶部
| 特征 | 参数 |
|------|------|
| 仅左侧偏心挂耳凸起，无任何居中半圆结构（彻底避专利）|

## 三、内部电子布局

| 区域 | 内容 |
|------|------|
| 左上区（挂耳下方）| 4G+GPS 双模陶瓷天线 |
| 上中区 | MK 20×14mm 腔体喇叭（前后壳密封音腔）|
| 中间主体区 | 主控 PCB 主板、Nano SIM 卡槽、定位模块 |
| 下半大区 | 503040 锂电 450mAh |
| 底部区域 | SOS 硅胶按键触点、振动马达 |

## 四、专利规避设计
- 无正竖长方形
- 无顶部居中挂耳
- 无正面正中大 SOS 键 → 下移
- 无四灯横向排布 → 双独立指示灯
- 无表面放射纹理
- 尺寸全卡鲁班尺财、本、义吉位
