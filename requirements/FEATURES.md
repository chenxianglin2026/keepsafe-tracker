# 功能列表与权重

> 基于 PRD 拆分为可执行的功能项，用于迭代排期和开发方案委派

---

## 优先级定义

| 级别 | 定义 | 要求 |
|------|------|------|
| **P0** | 核心功能，MVP 必须有 | 无此功能不发布 |
| **P1** | 重要功能，V1.0 完整版含 | 推荐包含，可延迟 |
| **P2** | 增强功能，V1.x 迭代 | 按资源安排 |
| **P3** | 远期规划 | 无时间承诺 |
