## 问题清单与处理方案

### 🅰 后端启动（可立即进行）

| # | 问题 | 处理人 | 动作 |
|---|------|--------|------|
| 1 | 后端缺乏 docker-compose.yml，需一键启动 PostgreSQL + Redis + EMQX | Architect | 编写 docker-compose |
| 2 | 后端缺乏 Dockerfile，没有容器化部署方式 | Architect | 编写 Dockerfile |
| 3 | 后端依赖未安装，未验证能否跑起来 | QA | 安装依赖 + 启动验证 |
| 4 | .env 密钥未填（DB/Redis/EMQX/推送） | 老板 ✅ 你填 | 从 .env.example 复制为 .env 填值 |
| 5 | 数据库 Migration 脚本未生成（alembic） | BE-Dev | 初始化 migration |
| 6 | 后端的 push/fcm.py apns.py 依赖外部凭证文件路径未创建 | BE-Dev | 建好目录结构 + 占位文件 |

### 🅱 硬件验证（需工具链安装）

| 9 | 固件未做静态代码检查 | QA | 编译检查 + 静态分析 |

## 执行顺序

```
第1波（立刻）               第2波（等密钥）            第3波（等结构图）
┌─────────────────┐        ┌────────────────┐        ┌────────────────┐
│ Architect       │        │ QA             │        │ iOS-Dev        │
│  docker-compose │        │ 启动后端验证    │        │ KEEP-002       │
│  Dockerfile     │        │ 接口冒烟测试    │        │                │
├─────────────────┤        ├────────────────┤        ├────────────────┤
│ Emb-Dev         │        │ BE-Dev         │        │ And-Dev        │
│  安装 ESP-IDF   │        │  生成 migration │        │ KEEP-002       │
│  编译固件       │        │                │        │                │
├─────────────────┤        ├────────────────┤        ├────────────────┤
│ Mech-Dev        │        │                │        │ MiniApp-Dev    │
│  安装 OpenSCAD  │        │                │        │ KEEP-002       │
│  渲染 STL       │        │                │        │                │
└─────────────────┘        └────────────────┘        └────────────────┘
```

## 所需你配合的事项

1. **外观结构图** — 这是启动 App 开发的关键输入，有了我就派 iOS/Android/小程序三组人干活
2. **填 .env 密钥** — 后端启动时需要 DB/Redis/EMQX 密码
