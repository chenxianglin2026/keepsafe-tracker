## 十、重要注意事项

### 烧录与编译

- **编译**: cmake 因 GitHub 网络限制卡住 → 建议用 Docker 编译 (espressif/idf:latest) 或开代理后编译
- **烧录工具**: esptool.py 5.2.0 已装, 用 USB 转串口或板载 USB-JTAG 烧录
- **Air780E 固件**: 合宙官方 LuatOS 固件, 通过 USB 转串口用 Luatools 烧录

### 开发板 vs 自研 PCB

| 模块 | 开发板代替方案 | 自研 PCB 焊接难度 |
|------|---------------|------------------|
| ESP32-S3 | ESP32-S3-DevKitC-1 (省心) | 模组邮票孔, 手工可焊 |
| Air780E | Air780E 开发板 (USB 转串口 AT 指令) | LGA 封装, 需热风枪/回流焊 |
| LIS3DH | GY-521/ADXL345 模块(3.3V) 暂代 | 3×3mm LGA, 需热风枪 |
| 马达/喇叭 | 直接用杜邦线飞线 | 简单焊接 |
| 天线 | IPEX 座直连 | 简单焊接 |

### 3D 打印注意事项

- 现有 STL: `/Users/chenxianglin/projects/keepsafe/code/hardware/keepsafe_body_v2.stl`
- 建议嘉立创 3D 打印 (¥15/套, 打印精度 0.1mm)
- 材质选 PETG (耐温 80℃, 强度好) 或 PLA (便宜)
- 内部容量需要实测验证 12mm 厚度是否能容纳所有堆叠
